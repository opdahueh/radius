# RADIUS – statische GitHub-Pages-Fassung

Dieses Repository enthält eine statische, responsive Rekonstruktion des öffentlich erreichbaren Webauftritts von RADIUS Psychologische Beratung und Coaching. Die Navigation, Unterseiten, Startseiten-Slider, Typografie, Farben, Abstände und Footer sind ohne WordPress/PHP umgesetzt.

## GitHub Pages
1. Alle Dateien in ein GitHub-Repository laden.
2. Unter **Settings → Pages** die Quelle **GitHub Actions** wählen.
3. Der enthaltene Workflow `.github/workflows/pages.yml` veröffentlicht die Website.

## Hinweise
- Die Website ist vollständig statisch; Kontakt läuft über `mailto:`.
- Die beiden großen Startseitenbilder sowie das ICF-Logo werden derzeit direkt vom öffentlich erreichbaren Originalserver geladen, damit die visuelle Vorlage erhalten bleibt. Für einen vollständig autarken Export können die Bilddateien lokal gespiegelt werden, sobald die Originalserver die Dateien wieder zuverlässig ausliefert.
- Die Inhalte orientieren sich am öffentlich abrufbaren Stand vom 1. September 2026.
